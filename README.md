# MentOS Kernel Modification Project

A small educational operating-system kernel project focused on understanding and modifying kernel-level behaviour.

## Project status
In progress. We will first establish a reproducible, unmodified MentOS build and boot baseline. The exact kernel change will be selected after inspecting the source and available tests.
